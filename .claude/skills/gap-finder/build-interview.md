# Build interview

Four questions, one at a time. Plain words. Write nothing until all four are answered.

1. **"In one sentence, what should it do?"** This becomes the `description`. If the answer covers two jobs, ask which one; a skill does one job.
2. **"What do you give it?"** A link, a file, a folder, a few words. These are the inputs. Ask what happens if one is missing: stop and ask, or use a default?
3. **"What should come out, and where should it go?"** A file, a message, a change to another file. Name the folder from `CLAUDE.md`'s placement rules.
4. **"What must it never do?"** Send anything, delete anything, guess a fact, spend money. These go under "Never" in the skill.

Then say back all four in four lines and ask "Right?" before writing.
