# Start here

This folder becomes your workspace: a place where an AI can find your files, follow your rules, and do real work for you. Setting it up takes three steps.

## 1. Put this folder somewhere you will keep it

Documents is a good spot. Do not leave it in Downloads.

## 2. Run setup

**Windows:** double-click `setup.cmd`.

If Windows shows a blue box that says "Windows protected your PC", click **More info**, then **Run anyway**.

**Mac:** right-click `setup.command` and choose **Open**. A box will say it is from an unknown developer. Click **Open** again.

The Mac version is new. If it stops, send us the file `setup/setup-report.md`.

## 3. Wait, then answer four questions

Setup installs for 15 to 30 minutes. A black window shows what it is doing. When it finishes, Claude opens in that window.

Your browser may open and ask you to sign in to Claude. Sign in, then go back to the black window.

Claude will ask you four questions. What you do. What work you want help with. How you like things filed. How you want it to sound when it writes for you. Answer in plain words. If you are not sure, say so and it will pick something sensible.

That is it. Claude builds the folders and tells you three things to try.

## What gets installed

Free, standard tools: Git, Python, Node.js, ffmpeg, a web browser engine, Claude Code, and a set of tools for reading videos, web pages, social posts and documents. About 500 MB in all. Nothing is sent anywhere. Nothing signs in to anything for you. Anything that needs your sign-in is listed at the end for you to do yourself.

## If something goes wrong

Run setup again. It skips what already worked. If Claude opened, ask it: "What failed in setup?" It reads the report and helps.
