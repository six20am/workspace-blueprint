# Agents

Read these in order. They are the whole map; nothing here repeats them.

- **The map:** `CLAUDE.md`. Folder layout, naming rules, how work moves between workspaces.
- **The router:** `CONTEXT.md` at this level, once setup has written it. It sends each task to the right workspace.
- **The workspaces:** each has its own `CONTEXT.md`. Load only the one the task needs.

If `CLAUDE.md` says the workspace is not set up yet, follow `setup/SETUP.md`.

Skills live in `.claude/skills/`. Read a skill's `SKILL.md` before doing the job it covers.
