# Start here

This folder becomes your workspace: a place where an AI can find your files, follow your rules, and do real work for you. Setting it up takes three steps.

## 1. Unzip it, then put the folder somewhere you will keep it

Right-click the zip file and choose **Extract All** (Windows) or double-click it (Mac). You get a folder with the same name as the zip. Move that folder to Documents. Do not leave it in Downloads, and do not run anything from inside the zip.

## 2. Run setup

**Windows:** open the folder and double-click `setup.cmd`.

If Windows shows a blue box that says "Windows protected your PC", click **More info**, then **Run anyway**. During setup, Windows may ask "Do you want to allow this app to make changes?" a few times. Click **Yes** each time, so stay nearby for the first ten minutes.

**Mac:** double-click `setup.command`. Your Mac will refuse it the first time. Open **System Settings**, go to **Privacy and Security**, scroll down, and click **Open Anyway** next to the setup.command message. Then click **Open** to confirm. (On a Mac older than 2024, right-click the file and choose **Open** instead.)

The Mac version is new. If it stops, send us the file `setup/setup-report.md`.

## 3. Wait, then answer a few questions

Setup installs for 15 to 30 minutes. A black window shows what it is doing. When it finishes, Claude opens in that window.

Your browser may open and ask you to sign in to Claude. Sign in, then go back to the black window.

Claude will ask you a few questions. What you do. Whether the two or three kinds of work it names are the right ones. Whether the folders it shows you look right. How you want it to sound when it writes for you. And whether there is anything it should never do without asking you first. Answer in plain words. If you are not sure, say so and it will pick something sensible.

That is it. Claude builds the folders and tells you three things to try.

## What gets installed

Free, standard tools: Git, Python, Node.js, ffmpeg, a web browser engine, Claude Code, and a set of tools for reading videos, web pages, social posts and documents. Several hundred MB in all (LibreOffice alone is 300 MB and more). Nothing is sent anywhere. Nothing signs in to anything for you. Anything that needs your sign-in is listed at the end for you to do yourself.

## If something goes wrong

Run setup again. It skips what already worked. If Claude opened, ask it: "What failed in setup?" It reads the report and helps.
