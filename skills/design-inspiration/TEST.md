# Test: design-inspiration

## The ask
"Design an Instagram carousel announcing our new Saturday hours. It looks boring every time I try."

## The input
The hours (a fact the person gives), the business name, and whatever logo or colors exist in the workspace.

## Done looks like
Five to ten carousel examples each described in one line before anything is made. The size and safe zone taken from Instagram's own help page. One direction (type pairing, accent, layout idea), each choice pointed at the example that showed it. The first slide shown for a yes before the rest are made. No example copied.
