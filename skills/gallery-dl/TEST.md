# Test: gallery-dl

## The ask
"Show me what photos this public gallery has, then download them." Done only with the person's yes for a private gallery.

## The input
A public gallery URL the person has rights to. A private gallery needs their sign-in.

## Done looks like
A preview list first with nothing downloaded, then original-size files in one output folder only after the person agrees. For a private gallery with no sign-in, the skill stops and asks.
