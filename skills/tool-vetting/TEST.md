# Test: tool-vetting

## The ask
"Do we need this tool?" with one link to a public repo.

## The input
One public repo URL, for example https://github.com/octocat/Hello-World.

## Done looks like
A one-row verdict from ADOPT, EVALUATE, WATCH, MINE, ALREADY or SKIP, with the install path, the license, what does that job here today, and a short note filed in the research folder. Nothing installed.
