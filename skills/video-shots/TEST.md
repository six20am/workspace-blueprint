# Test: video-shots

## The ask
"I want a 15-second promo for my booking page that looks expensive. Here's a screenshot and my logo."

## The input
The screenshot, the logo, what the page does, and the two shot libraries setup downloaded.

## Done looks like
A shot list of three to six plain lines with the card each one comes from, shown before anything is built. On a yes, the shots built in Remotion with the person's own picture, logo and words, a test still looked at first, then one mp4 beside their files. The person is told which shots were first-time builds. Nothing posted; no claim on screen the person did not give.
